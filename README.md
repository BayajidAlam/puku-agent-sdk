# Puku Agent SDK — Quickstart & Demo Guide

A lightweight, practical guide and working demo application showing how to build intelligent, autonomous AI agents using the official **`puku-agent-sdk`** (`v3.1.4`).

---

## 📖 What is Puku Agent SDK?

**`puku-agent-sdk`** is the TypeScript/JavaScript programmatic interface for building agents on top of `puku-cli`.

Instead of running the CLI manually in your terminal, the SDK allows your Node.js backend or scripts to:
- Send prompts and receive structured agent responses.
- Stream tokens in real time to terminals, web sockets, or UI clients.
- Constrain output to strict JSON schemas (perfect for document parsing & operational updates).
- Register custom in-process tools and expose them via MCP (Model Context Protocol).
- Manage multi-turn conversational agent sessions.

## 🚀 Quick Setup

### 1. Prerequisites
- **Node.js**: `v20.0.0` or higher (`node -v`)
- **Puku CLI**: installed globally:
  ```bash
  npm install -g @puku/puku-cli
  ```
  Verify installation:
  ```bash
  puku-cli --version
  ```

### 2. Install Project Dependencies
Clone or open this repository, then install:
```bash
npm install
```

### 3. Configure API Key
Create a `.env` file from `.env.example`:
```bash
cp .env.example .env
```
Add your Puku API key:
```env
PUKU_AI_API_KEY=pk_your_api_key_here
```
*(If you already logged into `puku-cli auth` on your machine, it will automatically use your existing credentials.)*

## 💡 Code Examples

### 1. Simplest Basic Query
```typescript
import { query } from 'puku-agent-sdk';

const stream = query({
  prompt: 'Explain what an agent is in 1 sentence.',
});

for await (const message of stream) {
  if (message.type === 'assistant') {
    for (const block of message.message.content) {
      if (block.type === 'text') {
        console.log(block.text);
      }
    }
  } else if (message.type === 'result') {
    console.log(`Cost: $${message.total_cost_usd}`);
    break;
  }
}
```

---

### 2. Real-Time Token Streaming
To stream tokens as they are generated by the model, set `includePartialMessages: true`:
```typescript
import { query } from 'puku-agent-sdk';

const stream = query({
  prompt: 'Write a haiku about programming.',
  options: {
    includePartialMessages: true,
  },
});

for await (const message of stream) {
  if (message.type === 'stream_event') {
    const event = message.event as any;
    // Inspect token delta
    if (event?.type === 'content_block_delta' && event.delta?.text) {
      process.stdout.write(event.delta.text);
    }
  } else if (message.type === 'result') {
    console.log('\nDone!');
    break;
  }
}
```

### 3. Structured JSON Extraction (JSON Schema)
Force the model to return typed JSON conforming strictly to your schema:
```typescript
import { query } from 'puku-agent-sdk';

const invoiceSchema = {
  type: 'json_schema' as const,
  schema: {
    type: 'object',
    properties: {
      invoiceNumber: { type: 'string' },
      totalAmount: { type: 'number' },
      currency: { type: 'string' },
      itemsCount: { type: 'integer' },
    },
    required: ['invoiceNumber', 'totalAmount', 'currency'],
  },
};

const stream = query({
  prompt: 'Extract invoice details from: "Invoice #INV-2026-09 paid $1,450.00 USD for 3 licenses"',
  options: {
    outputFormat: invoiceSchema,
  },
});

for await (const message of stream) {
  if (message.type === 'result') {
    console.log('Structured JSON:', message.structured_output);
    break;
  }
}
```

### 4. Custom In-Process Tools (MCP)
Define custom functions in TypeScript that the agent can invoke dynamically:
```typescript
import { z } from 'zod';
import { query, tool, createSdkMcpServer } from 'puku-agent-sdk';

// 1. Define custom tool with Zod parameter validation
const getWeather = tool(
  'getWeather',
  'Get current weather conditions for a city',
  { city: z.string().describe('City name') },
  async ({ city }) => {
    // Local business logic
    return {
      content: [
        { type: 'text', text: `Weather in ${city}: 22°C, Sunny with light breeze.` }
      ]
    };
  }
);

// 2. Wrap tool into an in-process MCP server
const server = createSdkMcpServer({
  name: 'weatherService',
  tools: [getWeather],
});

// 3. Query the agent with tool enabled
const stream = query({
  prompt: 'What should I wear in Tokyo today?',
  options: {
    mcpServers: {
      weatherService: server,
    },
    allowedTools: ['mcp__weatherService__getWeather'],
  },
});

for await (const message of stream) {
  if (message.type === 'assistant') {
    console.log(message.message.content);
  }
}
```

## 🛠️ Options Reference

Common options passed to `query({ prompt, options })`:

| Option | Type | Description |
|---|---|---|
| `model` | `string` | Model name or alias (e.g., `'puku-default'`, `'puku-ai-2.8'`). |
| `systemPrompt` | `string` | Custom system instructions for the session. |
| `outputFormat` | `object` | JSON Schema constraints (`{ type: 'json_schema', schema: {...} }`). |
| `includePartialMessages` | `boolean` | When `true`, emits real-time `stream_event` token chunks. |
| `mcpServers` | `Record<string, McpServerConfig>` | External or in-process MCP servers exposed to the agent. |
| `allowedTools` | `string[]` | Auto-approved tool names (e.g. `['mcp__service__toolName']`). |
| `env` | `Record<string, string>` | Custom environment variables forwarded to the subprocess. |
| `cwd` | `string` | Working directory for the agent execution. |

## 💡 Troubleshooting & FAQs

### Q: `puku-cli` not found?
Ensure `@puku/puku-cli` is installed:
```bash
npm install -g @puku/puku-cli
```
You can also explicitly set the path in `.env`:
```env
PUKU_CLI_PATH="C:\Users\<Username>\AppData\Roaming\npm\puku-cli.cmd"
```

### Q: How do I change the model?
Pass `model` in options:
```typescript
query({
  prompt: 'Hello',
  options: { model: 'puku-ai-2.8' },
});
```

### Q: How do I handle authentication?
The SDK automatically reads `PUKU_AI_API_KEY` from the environment or your `.env` file. You can also pass it explicitly via `options.env`:
```typescript
query({
  prompt: 'Hello',
  options: {
    env: { PUKU_AI_API_KEY: 'pk_...' },
  },
});
```
